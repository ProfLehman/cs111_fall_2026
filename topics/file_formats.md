# Common File Formats

## Common Image Formats

### JPEG

**JPEG (Joint Photographic Experts Group)** is primarily a **lossy** compression format.

### PNG

**PNG (Portable Network Graphics)** is a **lossless** compression format.

### BMP

**BMP (Bitmap Image File)** is typically a **lossless** format.

### HEIC

On iPhones, **HEIC (High-Efficiency Image Coding)** is primarily used in **lossy** compression mode by default.

### WebP

**WebP** is a versatile image format that supports both **lossy** and **lossless** compression.
